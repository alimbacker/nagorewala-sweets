# Nagorewala Sweets

Website for Nagorewala Sweet Stall, Nagore (since 1960): halwas, sweets and savouries,
a sweet box that sends the order on WhatsApp, and branch details.

- `index.html`, `assets/` - the website (works on any static host, including GitHub Pages)
- `assets/js/data.js` - menu, prices and kitchen photos

The `/admin/` editor needs PHP hosting and is kept out of this repository.
