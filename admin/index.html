Changes are saved to the website's GitHub repository. Paste the shop's GitHub access key once, and choose a password to unlock the admin on this device next time.

How to get an access key
  1. Sign in to GitHub as alimbacker and open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it "Nagorewala admin" and pick an expiry date.
  3. Under Repository access choose Only select repositories → nagorewala-sweets.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it and paste it above. Keep it private, like a password.
